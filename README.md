# Servant Launcher 🎮

Современный, быстрый и стильный игровой лаунчер для Minecraft, построенный на **Avalonia UI** и **.NET 9**.

---

## ✨ Основные возможности

* **Эстетичный интерфейс (Glassmorphism & Fluid UI)**:
  * Тёмная тема с неоновыми акцентами, матовым стеклом и плавными анимациями.
  * Кастомизация интерфейса: настройка тем, акцентных цветов, прозрачности и установка собственных фоновых обоев.
* **Управление сборками (Профилями)**:
  * Полная изоляция профилей (моды, настройки, ресурспаки и миры хранятся отдельно).
  * Поддержка всех загрузчиков: Vanilla, Fabric, Quilt, Forge, NeoForge.
  * Физический Drag-and-Drop карточек сборок для удобной сортировки.
  * Кастомные иконки сборок со встроенным редактором кадрирования/обрезки.
  * Импорт и экспорт в стандартный формат Modrinth `.mrpack`.
* **Умный контент-менеджер**:
  * **Drag-and-Drop импорт прямо в окно**: перетащите файлы `.jar`, `.zip` или папки из Проводника — лаунчер сам распределит моды, шейдеры, ресурспаки и датапаки по нужным папкам.
  * Включение и отключение компонентов тумблерами без удаления файлов.
  * Проверка обновлений модов с Modrinth в один клик.
* **Встроенный каталог Modrinth**:
  * Поиск и установка модов, ресурспаков, шейдеров и сборок без выхода из лаунчера.
  * Выбор версии игры и сборки перед установкой.
  * Многопоточная параллельная загрузка модов (до 6 потоков).
* **3D-гардероб и система скинов**:
  * Интерактивный 3D-манекен персонажа с вращением мышкой в реальном времени.
  * Поддержка Classic (4px), Slim (3px), HD-скинов и плащей.
  * Коллекция пресетов скинов с быстрым переключением и Drag-and-Drop сортировкой.
* **Мульти-аккаунты**:
  * Безопасная авторизация Microsoft (OAuth2) с сохранением лицензии.
  * Свободные офлайн-аккаунты по никнейму.
  * Мгновенное переключение без перезапуска лаунчера.
* **Встроенные инструменты**:
  * Менеджер миров с созданием резервных копий и экспортом.
  * Галерея скриншотов с полноразмерным просмотром и копированием в буфер обмена.
  * Цветной журнал событий (Логи) с подсветкой ошибок и умным поиском.
  * Автономный Java-менеджер с автоматическим скачиванием проверенных сборок Java от Mojang.
  * Интеграция с Discord Rich Presence.
  * Автоматическое обновление лаунчера "по воздуху".

## 🛠 Стек технологий

* **Язык**: C# 13 / .NET 9
* **UI Фреймворк**: [Avalonia UI 11.2](https://avaloniaui.net/) (Cross-platform XAML)
* **Архитектура**: MVVM (CommunityToolkit.Mvvm)
* **Графика**: SkiaSharp
* **Скрипты сборки**: PowerShell Core

## 🚀 Сборка из исходников

### Требования
* [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) или новее.
* ОС: Windows 10/11 x64.

### Сборка лаунчера и установщика

Запустите скрипт автоматической сборки в PowerShell:

```powershell
.\build.ps1
```

Скрипт выполнит:
1. Очистку временных файлов.
2. Публикацию автономного исполняемого файла лаунчера (`dist\launcher\ServantLauncher.exe`).
3. Упаковку payload и сборку инсталлятора (`dist\installer\ServantSetup.exe`).
4. Генерацию манифеста версии `dist\version.json`.
